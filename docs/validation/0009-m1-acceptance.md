## 发现与修正

- 受伤发生在 tick 末尾时，旧观察器的同 tick 限制会漏掉下一 tick 才消费的真实伤害。现允许同一实体在当前或前一 tick 的样本，并再次验证仍在线、存活且生命真实下降。
- 三条事件记忆曾占满私聊 context 消息槽，挤掉仍保留的显式偏好。现按预算打包来源标记，优先新近显式偏好，再放已验证事件；不无限扩容，不向共享会话导入私人内容。
- 验收助手曾缺 Forge pack 元数据、使用旧系统消息事件、重复拼接 Loom 绝对运行目录、首次伙伴 ID 绑定顺序错误、在偏好真正保存前发送下一消息，或漏采独立专服日志。相关失败记录保留；修正后重跑，不把中断、超时或未执行的断言记为通过。
- 坏存档样本的路径防护使用真实规范路径；没有为让测试通过而放松限定目录或“不覆盖原文件”的要求。

## 双真实客户端的共享与隔离

Fabric、Forge 普通 DedicatedServer 各由 MFAcceptA / MFAcceptB 两个独立开发客户端连接，均完整通过，两个客户端均 READY/PASS 且退出码 0。统筹助手独立读取双方 marker、启动元数据、fixture 摘要与专服日志，并核对安装 JAR 与上表一致。每轮五类私人/共享请求各恰好一次，首次问候两次，fixture 错误为零，双方收到全部必需断言。
