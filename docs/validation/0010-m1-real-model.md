2026-10-26，创作者提供临时有限额凭据并明确授权，统筹助手亲自完成 DeepSeek 官方 API 的真实调用、双加载器游戏运行和最终回复审阅。结合 [0009 的生命周期、普通专服与多人隔离证据](0009-m1-acceptance.md)，M1 验收通过；M2 和完整 Alpha 发布仍未完成。

## 服务与直接调用

使用官方 `https://api.deepseek.com/chat/completions` 和 `deepseek-flash`，遵循 [官方接口](https://api-docs.deepseek.com/api/create-chat-completion/) 与 [调用说明](https://api-docs.deepseek.com/quick_start/agent_integrations/)。正式 JAR 的 Java Provider 另外直接通过 HTTPS 和环境变量 Bearer 认证完成真实请求，返回中文并正确称呼合成测试用户。没有为测试改写或重建生产代码。

本次共 24 次真实服务请求尝试，包含连通性、正式 Provider 直接调用、失败轮和最终成功轮；每次生成上限 512 token、显式重试 0。未查询账户余额或声称确切费用。凭据只在受控进程内存与指定环境变量使用，没有进入源码、配置、命令行参数、证据或 Git；游戏子进程不继承观察代理使用的凭据。

## 通过的场景

Fabric 和 Forge 各在真正 IntegratedServer 中使用已验收的正式 JAR，分别通过：

- 首次见面、伙伴真实非致死受伤、退出并重新打开同一世界，各有真实模型回复到达客户端并 ACK。
- 统筹助手逐条阅读回复：欢迎相遇、确认伙伴受伤、欢迎重登与实际事件对应；默认语气温和，明确 AI 身份，无排他或施压要求。不是由关键词命中代替审阅，也没有冒充创作者本人试玩或新增独立人类审查。
- 冷却期间再次受伤和关闭主动发言后受伤不额外调用模型。
- 实际列表解析 UUID 后单条删除记忆，删除项不再进入后续请求，保留事实及三条事件仍在，记忆数量稳定。
- 真实聊天确认 AI 身份并返回本轮唯一验证码。
- 观察代理分别制造超时和断连，玩家收到正确中文反馈；游戏继续处理后续命令，记忆不变，客户端与服务端完整结束并保存世界。

两个成功轮源码均为 `9fc4361f6451bf91dc00c94a0c526e8e84c1ae84`，运行期间源码、helper 与 JAR 均未变化。逐项结果、原始证据哈希、请求计数、审阅依据和本地证据编号见 [结构化记录](evidence/0010-m1-real-model-results.json)。正式 JAR 与 0009 的 SHA-256 完全一致。

## 测试装置修正及失败保留

真实运行发现并修正：回复不必以工具发明的固定前缀开头；探针后缀位于 UUID 之后；实际超时提示分为模型层和会话层；世界重开及失焦时测试必须继续 tick。GUI 首轮缺显示环境、失焦暂停、一次真实服务迟到超时、关键词误判和命令解析失败均保留本地，未算成功。真实服务迟到时游戏已给出超时反馈，旧结果未恢复本轮流程。

“受到了点伤害”“挨了一下”等合法表达可能没有命中简陋词表，因此事件词表仅记录 `event_context_advisories`，统筹助手必须阅读原始回复判断是否对应事件。空回复、格式、中文、AI 身份、正文上限和禁止文案仍有机械检查；模型输出没有被替换成模拟回复。`semantic_passes` 是工具历史字段名，不能单凭该计数宣称语义正确。

原始 runner summary 仍保持 `passed=false`、命令退出 1，明确表示等待统筹审阅；其实际游戏子进程退出 0、全部自动检查通过。随后的 `parent-verdict.json` 与本记录才是最终审阅结论，没有回改原始结果。工具单测 17 项、观察代理自检 6 项通过；助手双端编译和实际运行通过。

## 保留范围

这是一组短时、合成测试对话的验收，不保证长期陪伴体验、所有模型表现或回答永不出错。诊断标记探针只验证上下文与路径，不作为模型解释记忆操作说明的准确性验收。原始回复只保存在本地 0600 文件，不公开凭据或私人聊天。观察代理仅做受控故障，没有关闭系统网络。

本轮真实服务测试为双加载器单机；普通 DedicatedServer 和两真实开发客户端隔离沿用 0009 同字节正式 JAR 的验收结果。专服 JVM 冷重启、M2 跟随/采集/性能和完整 Alpha 发布仍未验收。没有安装软件、系统升级、驱动修改或停止桌面，也没有创建 Release 或部署。
