## 保留限制

- Forge 开发服经 Gradle 管道未收到 `stop`；脚本终止外层进程后游戏执行保存，Gradle 外壳非零。独立 Fabric / Forge 安装直接启动时均能用 `stop` 退出且退出码 0。开发管道限制公开保留，不算玩法缺陷已修复。
- 开发客户端只完成加载与图形初始化；正式伙伴创建、聊天、记忆、导航、合规采集、多人隔离与长时间运行尚未验收。[Alpha 四格矩阵](../TESTING.md#运行环境矩阵) 保持未测试。
- 玩家实体不是正版认证账号；探针的直接挖掘原语和丢弃出站包连接不能直接当作生产动作与兼容实现。
- 当前模型仅离线 Mock / disabled；没有真实 Provider、API key 存储或网络推理。超时字段不是已实现的请求控制。
- 创作者已本人接受本次 Minecraft EULA；不替其他使用者作决定。未使用真实存档、真人账号或付费模型，未升级系统、内核或显卡驱动。
- 本轮不创建 Release 或版本标签，不自动部署或宣布 Alpha 可用。
