## M1 验收范围

当前代码包含伙伴生命周期、异步模型协议、私聊/显式共享、人设和记忆。公共自动化检查与两加载器编译已通过；严格生命周期 GameTest 的证据见 [0008](validation/0008-lifecycle-fixes.md)。历史 [0007](validation/0007-companion-lifecycle.md) 的部分验收不作为最新完成声明。

最新逐项结果与原始证据哈希见 [M1 验收记录](validation/0009-m1-acceptance.md)。

正式 JAR 需在真实 IntegratedServer 和独立 DedicatedServer 中验证创建、暂离、恢复、两种死亡掉落规则、中文命令/聊天、世界与玩家隔离、称呼持久化和清空。私聊与共享要检查实际接收者、邀请成员资格及退出；不能只测试直接服务 API。

本机 HTTP 协议模拟器只验证网络适配、上下文和回包路径，不是自然语言模型。本轮创作者已授权 DeepSeek，双加载器真实服务与最终回复审阅见 [0010](validation/0010-m1-real-model.md)。更换模型或公共边界变更时仍须重新验收。M1 通过也不替代上方含跟随、采集与性能要求的 Alpha 矩阵。

## 按改动选择验证

| 改动 | 应提供的证据 |
| --- | --- |
| 纯文档 | 链接与引用路径存在、内容符合当前状态、示例无密钥、Markdown 结构可读 |
| 公共规则 | 针对非法输入、状态转换、隔离、取消、迟到结果及去重的自动化测试 |
| 模型适配 | Mock 成功/错误/超时/取消；真实服务人工验证需明确服务与结果，凭据不得入日志 |
| 加载器、网络或生命周期 | 对应环境实机验证，包含专用服务器类加载、权限与断线；评估另一适配层影响 |
| 移动或世界修改 | 生存模式和最小测试地图中的真实执行，包含停止、不可达及资源不足 |

自动化检查不能代替游戏内行为验收。验证命令、关键结果和未测试环境写入 PR；纯文档不需要启动游戏。日常 PR 检查受影响范围，完整矩阵在公共边界变更和发布前执行。

## Alpha 核心场景

1. **身份与恢复**：创建伙伴，重复创建不重复生成；离开、重进、死亡和重生后归属及物品符合规则。
2. **聊天与隔离**：中文对话正常，普通聊天及其他命令不被拦截；两玩家并发不会串线，伙伴回复不会递归触发模型。
3. **陪伴与记忆**：明确告知称呼，重进后仍能正确使用；清空后不再引用旧记忆，在途请求也不能写回。主动发言有冷却。
4. **跟随与等待**：地面、台阶和小障碍地图中能跟随；等待后不继续追踪；不可达和卡住时在预算内退出并反馈。
5. **采集与交付**：主人指定可采集区域，在生存模式请求 8 个橡木原木；伙伴实际挖掘、拾取并交付给正确玩家，资源减少且无复制。
6. **停止**：分别在等待推理、移动、挖掘和交付前发送停止，记录请求时间与最后动作 tick；终态后无旧动作恢复，无重试重复交付。

固定地图和步骤应可复现，记录环境与期望，不把截图作为唯一证据。测试使用独立世界；未经用户许可不在珍贵存档中验证破坏性操作。

## 必测失败场景

- 缺少 API key、认证失败、限流、断网、超时和畸形响应：游戏不崩溃、不阻塞 tick，提示可理解且不泄密。
- 非主人请求、伪造身份/动作消息、超大输入、重复请求：服务端拒绝越权，限制请求，不产生重复世界修改。
- 玩家断线、世界卸载、伙伴移除及迟到响应：关联任务结束或取消，不访问失效世界。
- 背包满、工具不足、资源不足、目标不达或维度改变：按真实进度报告，不生成物品伪造完成。
- 存储损坏与恢复：不串档、不复制物品，报告错误并遵循已记录的恢复规则。
- 多人并发：一人的停止、记忆清除和模型响应不影响另一人。

## 性能与费用记录

同一测试条件记录关闭功能基线与开启后的 tick 耗时（说明采样方法与分位值）、感知/寻路耗时、内存、队列长度、模型调用频率及可获得的 token 用量。写清硬件、玩家数、地图和运行时间。

实现前为单 tick 工作、上下文大小、超时、重试和主动发言确定可配置上限。阈值必须有依据，超过时降级或退出并留下诊断；不得为了通过测试删除异常记录。模型服务费用以其实际计费为准，不承诺免费或固定费用。

## 发布门槛

只有四格矩阵、多人隔离、核心场景与必需失败场景均有通过记录，且所有 P0 发布阻塞已解决，才能声明初期双加载器 Alpha 达标。

发布检查包括：两个独立并能加载的 JAR、精确依赖与构建说明、配置示例、安装和升级/卸载说明、存档备份建议、已知问题、隐私与费用说明、依赖许可与创作者选定的项目许可证。README 必须与实际验证范围一致；未达标时保留为开发构建并显著说明限制。

发布者确认产物来自记录的提交且不包含凭据或测试存档，维护者完成发布审查后再创建版本标签和 Release。CI 上传构建产物不代表已授权正式发布。
